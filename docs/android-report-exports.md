# Android report exports

The existing XLSX/PDF generators are unchanged. Previously both download handlers used only a Blob URL and an HTML download link. The Android WebView had no native file-saving handler and the UI did not await or report a completed save.

Android now passes generated bytes to the registered BookingFileExport Capacitor plugin. ACTION_CREATE_DOCUMENT lets the user choose a single output document. No storage permission, broad directory grant, external service or new runtime dependency is required. Success is shown only after the output stream closes successfully; cancellation and errors are separate visible outcomes. Both export buttons are disabled while a picker/write is pending. Missing adapters fail visibly without attempting an unsupported Blob fallback.

Browser downloads retain their existing Blob transport and report that a download was requested, rather than claiming the browser saved the file. Current report filters, PREMIUM validation, generators, currencies and business storage remain unchanged.

## Limits

Choose a local Downloads/Documents location for offline operation. Cloud document providers may require a connection. Exports are limited to 24 MiB to bound native bridge memory. The temporary payload is kept in memory, never local business storage or Android activity-state bundles. If Android kills the process during the chooser, reopen the app and retry; pending exports are not resumable. Other app data is unaffected.

Automated browser tests mock the native bridge; they do not verify an actual Android document provider. Compilation and signing also do not establish real-device functionality.

## Phone verification

1. Install test 1.0.6 (versionCode 7) over 1.0.5 without uninstalling or clearing data. Verify existing reservations remain.
2. Enable airplane mode. With TRIAL/PREMIUM access, open Reports and select the desired period, apartment, status and RON.
3. Tap Export Excel, choose a local Downloads destination in the Android picker and tap Save. Check the saved-file confirmation. Open the file from Android Files using an XLSX reader and compare rows and totals with the filtered report.
4. Repeat Export PDF; open it with a PDF reader. Check Romanian diacritics, totals and multi-page headers where applicable.
5. Repeat for EUR; confirm no currencies are combined.
6. Cancel the picker once. Check cancellation is shown, without a success claim, and either export can be retried. If a provider refuses a write, check a readable error and retry in a writable local folder.
7. Close/reopen the app and verify reservations and payment histories remain unchanged. Also check browser downloads on desktop.
